# 导出卡片与图文交付

## 顺序与等待

先完成材料范围、审读正文和 Mermaid 源码，在会话中展示结果，再调用 `ask_user`。
这是 Wisp 已有的交互问题卡片，不是用 Markdown 模拟的选项列表。
每次调用后立即结束当前轮；用户答案在下一条消息到达。未答、取消、关闭或超时均不算同意。
一次只发一张卡片。若当前环境没有 `ask_user`，说明卡片不可用并等待用户明确选择，不能声称已弹卡或默认导出。

第一张卡片使用以下参数：

```json
{
  "question": "论文审读已完成，请选择导出格式。可在输入框填写多个格式；选择后还需确认当前模型具有视觉能力，用于检查渲染图和文档。",
  "options": [
    {"label": "Markdown (.md)", "description": "保留可编辑 Mermaid 源码，并附已渲染图像"},
    {"label": "Word (.docx)", "description": "英文 Times New Roman、中文宋体、小四、1.5 倍行距，插入已渲染图像"},
    {"label": "HTML (.html)", "description": "可离线打开的图文报告，嵌入已渲染图像"},
    {"label": "暂不导出", "description": "保留当前会话中的审读结果"}
  ],
  "allow_freeform": true
}
```

选择“暂不导出”即结束导出流程。格式不明确时只澄清格式，不猜测。
选择一个或多个格式后，保留该选择，发送第二张卡片：

```json
{
  "question": "导出需要模型查看 Mermaid 渲染图及文档页面，检查文字、连线和排版。请确认当前执行模型支持图像输入，且本会话可使用图像查看工具。确认本身不会切换模型。",
  "options": [
    {"label": "确认具备视觉能力，继续导出", "description": "继续实际渲染和视觉检查；工具失败时仍会暂停"},
    {"label": "暂不具备或不确定，稍后继续", "description": "暂停导出，切换到支持视觉的模型并确认后继续"},
    {"label": "取消导出", "description": "保留审读结果，不创建导出文件"}
  ],
  "allow_freeform": true
}
```

只有明确确认后才进行导出。若用户已经在本次导出中通过卡片明确回答过相应问题，沿用答案；模型切换后重新确认视觉能力。
不根据模型名称猜测视觉支持，不自动切换模型。用户确认后仍必须实际调用图像工具；失败时说明阻塞并保留已选格式，不能宣布视觉检查通过。
该导出确认不意味着此前已经看过论文图像；审读阶段始终如实标注文本推断与实际视觉观察。

## 渲染与交付

- 仅生成用户选择的交付格式；可保留必要的临时源码和渲染文件，但不能把它们冒充已完成的导出。
- 使用当前环境可用的 Mermaid 渲染器将每个图渲染成 PNG（Word 优先）或 SVG/PNG。使用本地工具，不把论文内容发送给在线绘图服务。
- 用视觉工具查看每张渲染图，检查中文缺字、截断、重叠、连线方向和证据标签；失败则修正并重新渲染检查。无可用渲染器或视觉工具时暂停导出并明确原因，不用代码截图替代图。
- Markdown：正文中保留 `mermaid` 代码块，并用相对路径插入渲染图片；图片放在同名资源目录，交付时同时链接该目录中的图片，说明分享时需一起携带。
- HTML：生成 UTF-8 独立页面，图像内嵌为 data URI 或内联 SVG，可离线查看；不依赖 CDN 或打开时才执行 Mermaid。正文和源码正确转义，源码可放折叠区。
- Word：插入已渲染图像，不把 Mermaid 代码当作图。按下一节设置格式。
- 所有格式保持相同材料范围、证据位置、局限和图注；不要在转换时新增论文结论。
- 优先采用用户指定路径，否则保存到项目 `artifacts/paper-audit/<论文短名>/`，使用不覆盖现有文件的名称。检查文件非空、图片引用可解析后返回实际文件链接。没有成功生成的格式必须明确说明。

## Word 固定排版

- 全文文字（含标题、表格、图注、页眉页脚）字号小四，即 12 pt；标题通过加粗和段前后间距区分，不放大字号。
- 英文及数字使用 `Times New Roman`，中文使用宋体（`SimSun`）。在 OOXML `w:rFonts` 中同时设置 `ascii`、`hAnsi`、`cs` 为 `Times New Roman`，`eastAsia` 为 `SimSun`；不能只设置西文字体名。
- 所有文字段落使用 1.5 倍行距（OOXML `w:spacing w:line="360" w:lineRule="auto"`），含表格单元格。图片放独立段落，可使用单倍行距以防裁切，图注仍为 1.5 倍。
- 创建后检查 DOCX 内的样式和显式 run/paragraph 覆盖，确保默认标题或表格样式没有改变字体、字号和行距。图片按页面可用宽度等比缩放。
- 使用环境中可用的 Word/LibreOffice 等文档渲染工具转成页面预览，逐页用视觉工具检查图像、表格和分页；禁止把仅检查 ZIP/XML 说成视觉验证。
- 缺少宋体或 Times New Roman 时不得静默以替代字体宣称满足要求；保留进度并说明需要安装字体。渲染工具缺失时说明尚未完成排版验收，不将未验收 DOCX 作为最终完成件。
