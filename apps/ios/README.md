# Wisp Science for iPhone and iPad

原生 SwiftUI 客户端，最低支持 iOS / iPadOS 17。连接现有的 Wisp 网页远程访问服务，
无需另建 iOS 后端，不在手机上启动 Rust Agent、Python 或 SSH 进程。

```text
iPhone / iPad ── WSS、端到端加密 ── wisp-relay ── 在线 Wisp 主机
```

**中继不执行计算。** Agent、模型凭据、项目和 Run 均在 Wisp 主机上。
目前服务端通道由桌面宿主提供；仅部署 `wisp-relay`，或仅运行 CLI，不能代替在线宿主。
主机如何部署和启用远程访问见 [远程接入说明](../../docs/remote-access.md)。

## 打开与安装

1. 用 Xcode 16 或更新版本打开 `apps/ios/WispScience.xcodeproj`，选择 `WispScience` scheme。
2. 选择 iPhone 或 iPad 模拟器。工程不依赖第三方 Swift 包；`WispRemote` 是本地 Swift Package。
3. 真机运行时，在 **Signing & Capabilities** 中选择自己的开发团队，并按需修改 Bundle Identifier。
4. 在 Wisp 主机启用「设置 → 远程接入 → 网页远程访问」，复制远程访问链接。
5. 在 App 中粘贴 `https://relay.example.com/remote#联机码`，或分别填写中继 HTTPS 地址和联机码。
   使用反向代理前缀时，如 `/wisp/remote#…`，App 会保留 `/wisp/`。

手机使用的是**联机码**，不是中继管理员的 `WISP_RELAY_TOKEN`。连接成功后凭据保存在设备
钥匙串中；「连接 → 忘记连接并更换服务器」会删除本机凭据，并清空本次会话的内存数据。
同时删除当前服务器的本机缓存。
App 当前保存一个连接。链接中的项目、会话导航片段不会自动打开对应内容。

## 本机缓存与离线查看

已查看的项目列表、对话列表、对话快照、加载过的历史页、文件目录、文本预览和图片保存在本机缓存。
打开页面时先显示缓存，再请求服务器更新；相同的并发读取合并为一次请求。
断网或主机离线时，可进入已缓存的项目与对话，打开之前查看过的文件；没有缓存的内容会提示联网加载。
缓存视图标明保存时间，项目／任务状态以联网刷新为准。旧快照中的发送、审批、停止和队列操作
保持禁用，重连后拿到当前连接的新快照才恢复；没有离线对话发送队列，不会自动重放会话操作。
科研清单有独立的数据同步机制，见下文。

- 缓存按中继地址和联机码派生的服务器标识隔离，键还包含项目、会话与文件路径。
- 默认总量上限 50 MB、单条上限 8 MB，最多 500 条；保留 30 天，超限优先淘汰较久未访问的内容。
- 缓存使用系统 Caches 目录，排除备份，并采用 iOS 文件保护；系统可回收，卸载 App 会移除。
- 联机码仍只放钥匙串，不写入缓存；不自动同步完整项目或大型科学数据。
- 「连接 → 离线缓存 → 清除本机缓存」清理所有服务器的缓存，保留联机码及当前页面内容；后续读取会重新缓存。
- 演示模式直接读取随包资源，不使用远程缓存，也不会混入真实服务器的缓存。

## 离线演示与审核体验

连接页点击 **「体验演示项目」**，再选择 **「RNA-seq 质控 · 演示」**。无需填写服务器地址、
联机码或账号；飞行模式下也可使用。入口和 `DemoData` 资源在 Debug、Release 构建中均保留，
与仅用于自动测试的 `PreviewHost` 无关。

- 「样本质控与报告」：6 个合成样本、Markdown 表格、比对率图表、成功 Run 的命令／日志。
- 「分析流程与审批」：失败 Run 示例，以及可批准、可拒绝的本地审批。
- 「问题与选项」：三项可点击的模拟选项，可切换或取消选择、填写补充说明，再提交回答。
- 「文件」：样本 CSV、质控指标 CSV、Markdown 报告、PNG 图表、只供阅读的 Python 示例脚本。
- 可以发送文字、点选建议；回复明确标为本地预设内容，不调用 AI 或执行分析。

页面始终显示「离线演示 · 合成数据」。提示条独立排列在系统导航栏上方，
与「演示设置」「待处理」及返回按钮分开布局；大字号时提示文字可换行。
演示不会联网、上传图片、执行命令、写项目文件，
也不读取或改写钥匙串。进入演示会断开已有远程连接，保留已保存的联机码。
演示模式选择保存在本机 `UserDefaults`；重启后仍进入演示，避免自动连接真实主机。
本次消息、选项回答和审批仅保存在内存；重启、退出或「演示设置 → 重置演示数据」恢复初始内容。
点击顶部「退出演示」返回连接页。演示不提供新建对话、图片上传或真实计算。

演示数据和图表来源于 `scripts/build_demo_dataset.py` 中显式定义的合成数值。修改后可运行：

```bash
uv run --no-project --with matplotlib python apps/ios/scripts/build_demo_dataset.py
```

仅生成资源时需要 Python / matplotlib；安装后的 App 不依赖它们。
`PrivacyInfo.xcprivacy` 中以 `CA92.1` 声明仅用于本 App 模式偏好和对话信息详细程度的 UserDefaults 访问，
对应 [Apple 的 API 使用原因说明](https://developer.apple.com/documentation/bundleresources/app-privacy-configuration/nsprivacyaccessedapitypes/nsprivacyaccessedapitypereasons)。

可在 App Review 备注中说明：

> No account or server is needed to explore the bundled demo. On the connection screen, tap
> “体验演示项目” (Try demo project), then “RNA-seq 质控 · 演示”. The three conversations demonstrate
> reports, charts, run logs, project files, approval interactions and selectable question options. All demo data is synthetic;
> messages receive clearly labeled local preset replies and no commands or AI analysis are executed.
> To leave the demo, tap “退出演示” (Exit demo). Real remote execution requires the user's own Wisp host.

Debug 构建使用 `ONLY_ACTIVE_ARCH=YES`，与本地 Swift Package 在所选模拟器上的架构一致。
Release 保持全架构构建。若旧工程曾显示 `Unable to resolve module dependency: WispRemote`
并伴随 `built for incompatible target`，重新加载更新后的工程再构建；仍有旧诊断时可执行
**Product → Clean Build Folder** 后重建，不需要下载或手动添加 `WispRemote`。

## 与网页端对应的功能

| 功能 | 原生客户端 |
| --- | --- |
| 项目和对话 | 项目列表、按最近活动排序并显示时间的对话列表、新建对话、下拉刷新 |
| 对话阅读 | 最新快照、较早消息、Markdown 标题／表格／代码／链接／图片、工具与思考折叠、简洁／标准／详细三档信息详细程度 |
| 发消息 | 文本、最多四张图片、运行期间排队、取消排队、停止 |
| 审批 | 批准一次或拒绝；不提供永久授权 |
| 问题选项 | 原生 `ask_user` 问题卡片、单选、补充说明或直接输入回答；确认后提交 |
| Run | 会话所属 Run 状态、命令与输出尾部 |
| 文件 | 目录、文本和图片预览、服务端已转换的 PDF／Office 文本 |
| 待处理 | 跨项目待处理列表、跳转对话、阅读后标记已读 |
| 科研日历 | 月视图、周一开始的日期网格、今天、活动标记、项目筛选与独立的当日读取 |
| 研究历程 | 按本地日期及会话分组、记录摘要／来源／产物版本、跳回关联对话 |
| 科研清单 | 离线添加、改期、完成／移出，恢复连接后与桌面研究计划双向同步，保留冲突供选择 |
| 实验记录本 | 离线拍照／选图、原图留存、设备文字识别与校对，选择页面后发送到指定项目对话 |
| 设备布局 | iPhone 底部标签与逐层导航；iPad 侧边栏汇总工具与项目，列表与详情并排，随横竖屏和窗口宽度调整 |
| 生命周期 | 前台轮询、后台断开、回到前台重连并重新读取状态 |

iOS 发起的任务默认对修改类工具请求审批。在电脑端为**同一条会话**开启“完全权限”后，正在执行和后续的 iOS 回合都会采用该授权，包括 `run_in_context`，无需每次重新批准。关闭后恢复审批，重启电脑端 Wisp 后授权失效；每轮只使用目标会话的授权。显式禁止、研究职责的“先问我”和课题组来信的审批要求仍然生效。

界面使用中文、系统字体、动态字号和系统明暗外观。
项目列表与对话列表使用单行导航栏，标题与连接、待处理或新对话操作共用一行，减少列表上方留白。
项目列表两侧使用等宽的齿轮（连接／演示设置）和托盘（待处理）图标，保留 44 pt 点击区域。
连接、待处理、工具页返回、新对话、记录本帮助和对话文件统一使用 `WispToolbarButton`：
分别用齿轮、托盘、左箭头、方框铅笔、问号和文件夹表示，不再出现宽度不一的文字胶囊。
对话页文件按钮右侧的「信息详细程度」同样使用 `WispToolbarButton`（滑杆图标），VoiceOver 读出当前档位。
按钮沿用系统导航栏背景，与系统返回控件一致；iOS 26 起使用中性色图标，旧版使用主题色。
工具页返回只显示左箭头；项目／对话及详情页保留系统返回和原有侧滑手势。保存／关闭弹窗的「完成」仍保留文字。
仅有待处理事项时显示数量角标（超过 99 显示 `99+`）；为空时图标置灰且不可点击，不显示「待处理 0」。
VoiceOver 仍读出操作名称及完整数量；辅助功能大字号下，长按图标可查看放大的文字提示。
对话列表每行右侧显示最近活动时间：当天显示时刻（如 09:05），前一天显示「昨天」，更早显示月日或年月日；
按最近活动从新到旧排列，主机未提供时间的行保持原顺序排在后面。辅助功能大字号下时间移到标题下方。
底部标签栏提供「对话」「日历」「清单」「记录本」四个入口，图标来自 `compose_icon()`。
每个标签保留自己的逐层导航和滚动位置，切换标签后回来仍停在原处；标签根页没有「返回」，Escape 与左边缘侧滑
在标签根页不做任何事，只在标签内的详情页逐层返回。未配对时第一个标签显示为「连接」（齿轮图标），
没有「日历」；「清单」和「记录本」无需主机即可使用。离线演示只显示「对话」和「日历」，不混入个人的离线记录。
iPhone 进入对话后隐藏标签栏，输入框占据底部；返回对话列表后标签栏恢复。iPad 布局见下文「iPad 侧边栏」。
项目中的「研究历程」仍是对话列表之上的完整页面：点击左上角「返回」或从屏幕左边缘向右滑动回到对话列表，
侧滑时页面跟随手指，短距离拖动或向左滑回会取消返回；详情使用系统逐层导航，一次侧滑只退一层。
研究历程和「日历」标签各自使用独立的详情导航，互不弹出。从研究记录打开关联对话时自动切换到「对话」标签。
工具标签或研究历程显示期间，背后的对话不会自动标记已读。
对话采用中性背景与深色正文，Run／工具记录为紧凑的折叠行；
成功、失败和待审批状态分别使用绿色、红色和琥珀色，始终保留文字状态。
连续的工具调用、思考、文件变更路径和已结束轮次的中间说明，默认合并为一条「执行过程」。
摘要显示步骤数、去重后的文件数与失败数；展开后按原顺序浏览，工具输入／输出仍可单独展开。
最终回答、提问、计划及系统提示保持可见；当前运行中的说明和待审批卡片也不会收进执行过程。

对话页右上角的「信息详细程度」（滑杆图标）打开一个半屏面板，列出三档及简短说明，当前档位带勾选；
点选后立即生效并关闭面板，Escape 只关闭面板而保留对话。它只改变本机的呈现方式，不向主机发送任何内容：

- **简洁**：不显示中间的工具调用、思考和文件变更，也隐藏用量统计。没有失败的「执行过程」整条省略；
  有失败的显示为红色的「N 项失败」提示，点按后展开该段执行过程，再点按收起。
  当前运行中的说明、「运行中…」状态行、提问、计划、系统提示、待审批卡片，以及生成图片／视频、
  完成结果和运行监控等独立工具照常显示。
- **标准**（默认）：即上文的「执行过程」合并方式。
- **详细**：每条消息、工具调用和思考单独成行，按原顺序显示；工具与思考默认展开，仍可逐条收起。

选择保存在本机（`UserDefaults`），对所有对话生效，重启后保留，不随连接或主机变化；切换档位后折叠状态按新档位的默认值重置。
三档的取值、名称及每档应得到的行由 `contracts/native-conversations/v1/transcript-detail.json` 固定，
Android 客户端使用同一份约定。界面测试每次启动都使用独立的临时偏好，测试中的选择不会带到下一个测试。

待审批卡片或尚未回答的问题滚出可视区域时，输入框上方显示琥珀色提醒，例如「需要你批准：shell」，
多项时显示总数；点击后滚动到对应卡片，卡片回到可视区域后提醒自动消失。
发送、图片上传、审批、停止、取消排队和回答问题失败时，错误显示在输入框上方，不再占用页面顶部横幅；
顶部横幅只用于连接地址等工作区级错误。主机明确拒绝的发送和图片上传提供「重试」：发送重试沿用当前草稿，
上传重试使用原图。超时或断线导致结果未知时只提示核对，不提供重试，避免重复发送。
生成图片／视频、完成结果和运行监控等工具保留独立入口。普通刷新及追加步骤保留展开状态，
切换对话或快照历史窗口变化时重新收起。
运行记录默认显示失败、进行中等非成功状态；已完成的记录合并为一行，点开后可逐条查看命令和日志。
用量统计默认折叠，展开后显示输入、输出、缓存和上下文等数值；原始 JSON 在二级详情中保留。
`question` 消息解析为问题和选项，不显示协议 JSON 与给 Agent 的内部备注。默认不预选；点选后可以
切换或取消选择，允许自由回答的问题可填写补充说明，也可不选任何选项直接输入回答。
「提交回答」沿用原生会话的消息发送通道，包含选项标题、说明及补充文字，不覆盖主输入框的草稿或图片。
后续用户消息或成功提交会将问题标为「已回答」；提交中禁止重复操作，明确失败后保留选择供重试。
若发送超时或断线而无法确认结果，显示待确认状态，不自动重发；需刷新或到主机确认结果。
缓存、只读、运行中、已过期的问题不能提交；ACP 问题仍需在桌面端回答。无法解析的旧问题保留原文。
长对话标题从中间省略，保留开头和结尾，点击标题可查看并选择复制完整标题及所属项目。
向上翻阅时显示「回到最新」，点击返回底部；自动跟随依据底部是否接近可见区域判断，避免懒加载提前触发跟随。
建议问题左对齐、完整换行，点击仅填入草稿；输入区整合图片、停止和发送按钮。
大字号时 Run 的状态移到标题下方，图片入口与发送操作分行；iPad 对话与输入区居中，内容最大宽度为 780 pt。
图片、发送、折叠、向下箭头及信息详细程度的滑杆从 `ui/src/app_support/messages.rs` 的 `compose_icon()` 导出，
没有引入第二套图标。修改共享图标后运行 `python3 apps/ios/scripts/export_icons.py` 更新 iOS SVG 资源。
硬件键盘 `⌘ Return` 发送消息；窗口级 Escape 关闭最上层 App 面板并保留对话。

### iPad 侧边栏

iPad 全屏、横竖屏和较宽的分屏窗口（常规宽度）不再显示浮动标签栏，改用一个侧边栏：上方是「科研日历」
「科研清单」「实验记录本」（未配对时为「连接」「科研清单」「实验记录本」，离线演示只有「科研日历」），
下方是主机的项目。选中项目时为「对话列表｜对话」两栏；选中工具时为「工具列表｜详情」两栏：
日历的月视图旁显示所选日期的研究记录，清单旁显示事项详情，记录本旁显示记录、帮助、示例与发送页面。
详情栏的更深层页面在详情栏内逐层推入，Escape 每次只关闭一层；关闭清单事项或记录后，详情栏回到提示页，
列表保持不动。正在打开的清单事项和记录在列表中高亮。项目「研究历程」仍是覆盖工作区的完整页面，
切换到其他工具时让出位置，回到对话时恢复。连接表单的输入和清单快速添加的文字在切换工具或窗口宽度时保留。

窗口宽度不少于 1100 pt（横屏）时三栏并排；竖屏时列表与详情并排，侧边栏收进左上角按钮，选择后自动收起；
更窄的窗口（如分屏）中列表浮在详情之上：未打开内容时显示列表，打开对话、事项或记录后详情占满宽度，
点左上角按钮再回到列表，与「邮件」一致。未配对时连接表单在窄窗口中直接占满详情栏。
Slide Over、窄分屏等紧凑宽度及 iPhone 继续使用底部标签栏。

iPad 选中行使用较深的青绿色填充，深色外观下白色文字与状态角标仍然清楚。指针悬停时，行按钮、发送按钮、
日历日期、项目筛选和清单圆圈显示高亮。文件浏览在 iPadOS 18 及以上使用页面尺寸的弹窗。
硬件键盘与 iPadOS 菜单栏提供：`⌘1` 对话（未配对时为连接）、`⌘2` 科研日历、`⌘3` 科研清单、`⌘4` 实验记录本、
`⌘N` 新对话（已选项目、非演示、主机支持时）、`⌘R` 刷新对话或日历；长按 `⌘` 可查看。
弹窗、相册或相机打开时这些快捷键不可用，不会切换底层页面。

### 科研日历与研究历程

项目列表顶部的「科研日历」汇总主机上的项目主线研究记录；进入项目后，可从对话列表顶部
打开「研究历程」。日历支持切换月份、回到今天和按项目筛选；选择日期会独立请求当天记录，
再点「查看当日研究历程」按会话浏览。历程也可按月浏览；记录详情显示摘要、研究时间、
补记时间、来源和产物版本。有会话来源且来源未被丢弃时，可点「打开关联对话」继续工作。
来源不存在或主机已删除会话时，会由现有对话读取通道提示失败；项目级手记不虚构关联对话。

日期以手机当前时区的公历计算，周一开始，支持跨年、闰年和夏令时。每次查询最长 32 天，
每个项目最多返回 2000 条记录，截断时明确提示；月度活动标记不完整时仍可按日重新读取。
项目读取失败与空日期分别显示。大项目列表分批查询，不会静默省略后面的项目。
记录详情、当日历程、日历组成同一个导航栈；硬件键盘 Escape 每次只返回一层，最后回到工作区。

此功能需要主机在 `hello.commands` 中提供 `native_research_calendar` 和
`native_research_journey`；旧版主机会显示更新提示。读取沿用主机隐私过滤与主线作用域，
切换连接或日期后丢弃过期响应。研究记录只保留在当前页面内存中，不加入持久离线缓存；
真实主机断线时需重连查看。离线演示包含今天及前一天的合成研究记录，可直接体验整个流程。
目前提供记录阅读与对话跳转；手动补记、修改记录、每日回顾编辑及产物原始版本预览仍在主机完成。

### 科研清单与实验记录本

未配对和已配对时都从底部「清单」「记录本」标签进入。清单和实验记录保存在
Application Support 的 `WispResearch-v1` 目录，采用原子写入和 iOS 完整文件保护。
它们是用户创作的数据，不受读缓存的容量和过期淘汰影响；清除缓存、忘记连接都不会删除它们。
读取失败会保留原文件并停止覆盖写入。数据可随系统设备备份保留；没有云同步服务，卸载前需自行备份。

清单首页以任务列表为主体：按「逾期」「今天」「接下来」分组，空分组不占位置，每行左侧圆圈可直接
完成或恢复待办；点击事项文字打开详情，可修改标题、改期或移出。已完成事项默认折叠，需要时展开。
同步冲突单列在「待确认」，即便某一端已完成或移出也不会被折叠；确认前不能直接勾选。
底部固定的快速添加栏只需输入事项并点「添加」，也支持键盘完成键，计划日期默认为当天。
首次使用和待办全部完成时显示不同空态；顶部只保留清单名及待办数。右上角齿轮打开清单设置，
集中切换本机／主机清单、查看保存同步状态或手动同步；异常提示仍在主列表可见，点开可看完整说明。
清单设置参与窗口级 Escape 返回栈，关闭后保留底层列表和未添加的文字。
实验记录本首页先问「你现在想做什么」，
提供「拍下纸质实验记录」「记下刚才的观察」「先看一条示例」三个入口，下方列出本机记录。
顶部「怎么用」可反复查看记录、校对、保存与发送说明；教学示例只供阅读，不会加入用户记录。
相册和拍照仍使用系统弹层，Escape 优先关闭它们，保留下方的实验记录编辑页面；帮助、示例、
校对及保存结果使用页面内导航，同样逐层返回。

**科研清单：** 快速新增默认安排在今天，通过圆圈标记完成，事项详情可改期或移出清单。未绑定的本机事项在首次成功连接
真实主机后归入该主机；随后按中继与联机码标识分别保存，切换主机不混合已有事项。
离线修改先落盘，前台连接成功后及每 15 秒同步；旧版主机保留本机编辑并提示更新。
主机需提供 `native_research_checklist_sync`。事项复用科研助理的「研究计划」数据，手机新增项
不绑定项目或对话；同步本身不启动 Agent，也不自动派发任务。
同步比较数据库递增版本，不使用手机时间决定覆盖。修改冲突保留手机版本与主机版本，用户选择后继续。
删除使用 `dropped` 状态，防止断线重试复活事项；隐私项目不可见且不可改写。检测到主机数据库更换
或游标回退时先重新读取，已有手机记录需确认；长列表分页，进度落盘。已下发的数据仍属于本机副本。

**实验记录本：** 选择「记下刚才的观察」即可写文字，日期默认为今天；标题可以稍后补，
留空时用观察的第一行生成标题。点右上角「完成」后保存文字，显示保存结果与回记录本的入口。
打开空白编辑页或取消相机／相册不会新建空记录；尚未点「完成」的文字修改不会自动保存。
选择「拍下纸质实验记录」时，先显示拍照／相册入口和下一步说明；相机不可用时提示改用相册。
可以从系统相册一次选最多 10 张，每条记录最多 50 张、单张最多 40 MB；首次导入有效照片时
才建立记录。原图落盘后进行设备识别，再打开第一张导入照片的校对页；其他照片可从该记录逐张打开。
导入期间离开页面不会强制跳回校对页，已导入内容仍可在本机记录中找到。识别失败也不丢图。
使用 Apple Vision `VNRecognizeTextRequest` 在设备上识别中英文，可查看并保存校对文字；
不需要 Apple Intelligence 账号或在线模型。已有文字不会被再次识别覆盖。手写、公式、单位和样本编号
需要人工核对；可以选择「暂不校对，先完成记录」，保留原图及已有识别文字，稍后继续。
相册中只存于 iCloud 的图片需要先下载。相机授权仅用于拍摄，选图使用系统 PhotosPicker。

保存结果明确区分「已保存在本机」与是否曾向主机发送，并提供返回列表、继续编辑和可选的整理入口。
点「选择内容，交给 Wisp 整理」后，依次选择内容、项目和已有对话，再核对并确认发送；
未连接时说明如何从电脑端获取连接链接，以及本机记录仍然保留。
默认不勾选照片，发送前可以预览文字；每次最多 4 张照片和 64 KB 文字。
确认后才上传所选图片的压缩副本（单张最多 560 KiB），手机原图不变；内容作为用户消息进入目标对话，
触发 Wisp 整理实验记录。记录保留最近一次发送的主机、对话、页面与结果。
发送前检查当前对话可写且空闲；不会把内容发到只读 ACP 对话。发送中断且结果未知时停止重试，
需要在目标对话核对，并明确选择「已核对未收到，允许重新发送」后才能再次操作。
记录文字、照片和识别结果不会因连接恢复而自动上传。暂不支持完整笔记本归档导出、跨设备笔记编辑同步、
页面裁切／排序／删除、后台上传或全文手写理解；若分多批发送，应分别选择页面。

与当前网页版相同，ACP 对话只读；终端、计算 Notebook、模型／Plan 设置、Run 取消／收获、
非图片上传和文件下载需要在主机完成。SVG 当前显示源码；PDF／Office 不提供原版排版预览。
没有后台常驻连接或推送通知；离线内容包括读缓存、本机科研清单和实验记录，不是完整项目副本。
断线期间输入的草稿保留在内存中，退出 App 后不保留。

## 协议和实现边界

- `Sources/WispRemote`：纯 Foundation / CryptoKit / Security 连接层、值解码、快照分页和 Markdown 分块。
- `RemoteReadCache`：独立 actor 管理有界磁盘／内存读缓存，过期和容量淘汰；清理会使清理前的写入票据失效。
- `WispScience`：SwiftUI 界面、图片缩小、窗口级 Escape，以及前后台生命周期。
- `WispScience.xcodeproj`：独立通用 iOS App，不修改现有 Tauri 或 macOS 工程。
- wire contract 继续由 `crates/wisp-dto` 定义；Swift 从通用 JSON 值读取已有字段，测试读取仓库的 `contracts/` 夹具。
- 握手和帧格式直接对应 `crates/wisp-sync/src/remote.rs`、`remote.js` 和
  `src-tauri/src/channels/remote.rs`。功能必须先出现在主机的 `hello.commands` 中。
- HTTPS / WSS 必需，拒绝凭据嵌入 URL、查询参数和重定向。不增加 ATS 任意加载豁免。
- 联机码通过方向绑定的 AES-256-GCM 加密帧使用，仅派生 rendezvous ID 出现在网络 URL 中。
  联机码在收到经验证的 hello 后才写入 `WhenUnlockedThisDeviceOnly` 钥匙串。
- 每条连接独立 nonce / 递增序号，发送队列串行化。请求超时或断线会向用户报告结果可能未知，
  不自动重发会话操作。科研清单的幂等数据同步通过独立的版本比较协议重试。
- 图片先通过 ImageIO 缩小，再编码为最大 560 KiB JPEG，遵循网页端的单帧上传上限。
- 科学数据仍由服务器持有；只按需读取有界快照、预览和图片。

原生导航采用 Apple 的 [NavigationSplitView](https://developer.apple.com/documentation/swiftui/navigationsplitview)，
网络采用 [URLSessionWebSocketTask](https://developer.apple.com/documentation/foundation/urlsessionwebsockettask)。
