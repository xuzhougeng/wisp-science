让每一次科研试错，都成为可验证、可复用的认知资产

Wisp Science 不是套在聊天框外的一层壳，而是一套面向科学发现的智能体工作台：人在回路的协同推理、可证伪的假设分叉、不可改写的阶段封存，以及程序性知识的持续结晶。全部本地运行，开源可审计。

[ T-01 ] 核心范式

人机协同的递归式科研闭环

科学发现从来不是一次性的问答，而是提出、分叉、确证、结晶的螺旋上升。Wisp 把这条回路的每一环都做成一等公民：每一轮反馈都以结构化的形式保存下来，并抬高下一轮的起点。

  1. 提出

    协同推理 · Co-reasoning

    在常驻 Python／R 内核与约 80 个科研数据库之上，研究者与智能体围绕同一个项目共同推理。

  2. 分叉

    反事实探索 · Counterfactual exploration

    从任一结论处建立不可变检查点，并行展开相互隔离的竞争性假设。

  3. 确证

    证据裁决 · Evidential adjudication

    比对分支差异，将胜出的假设原子化并入主线，其余候选彻底清理。

  4. 结晶

    知识沉淀 · Knowledge consolidation

    将研究阶段封存为不可改写的里程碑，把验证过的流程蒸馏为可复用的技能。

[ T-02 ] 关键技术

五项关键技术，支撑可信的科学智能体

每一项都已在当前版本中落地，并对应到可以直接使用的命令或界面入口。

Procedural Knowledge Crystallization

程序性知识结晶

一次成功的研究流程，不应只躺在聊天记录里。Wisp 将经过验证的会话轨迹蒸馏为结构化的程序性记忆：保留方法论中的不变量——步骤、模板与核验规则，剥离一次性的路径、课题与结论。技能以渐进式披露（progressive disclosure）按需加载，不挤占上下文窗口，让方法论跨会话、跨项目迁移。

落地为：/save-as-skill → SKILL.md，search_skills / use_skill 渐进加载。阅读教程

Ships as: /save-as-skill → SKILL.md, loaded progressively via search_skills / use_skill. Read the tutorial

Counterfactual Hypothesis Branching

反事实假设分叉

科学的本质，是在多个竞争性假设之间作出裁决。Wisp 在任一回答处建立不可变检查点（immutable checkpoint），派生彼此隔离的探索分支：每条分支拥有独立的工作区、产物、运行、决策与外部资源记录；裁决完成前主线被冻结，杜绝交叉污染。经差异比对后，「设为主线」将胜出的假设原子化并入主线，其余候选连同残留一并清理——这就是计算科研中的证据确证。

落地为：探索分支（开始探索 · 查看差异 · 设为主线），以及轻量对话分支 /fork。阅读说明

Ships as: explorations (Start exploration · View diff · Set as mainline), plus lightweight conversation branches via /fork. Read the guide

main ──●── checkpoint · immutable
       ├─ 探索 A  Leiden res=0.8    独立工作区
       ├─ 探索 B  Leiden res=1.2    独立工作区
       └─ 探索 C  去批次后重新聚类     独立工作区

主线冻结 ─ 查看差异 ─ 设为主线
→ 胜出假设原子并入，其余候选清理
main ──●── checkpoint · immutable
       ├─ explore A  Leiden res=0.8   isolated
       ├─ explore B  Leiden res=1.2   isolated
       └─ explore C  batch-corrected  isolated

mainline frozen ─ View diff ─ Set as mainline
→ winner merged atomically, others cleaned up
Epistemic Milestone Sealing

认知里程碑封存

研究阶段完成后，它的问题、结论与局限、参数选择依据、关键脚本与数据被封存为研究历程中的里程碑：文件以校验和固定为快照，会话转为只读，此后的发送、压缩、撤销与删除都无法改写这段历史。新的发现可以修正旧结论，却永远不会覆盖它——这是面向科研的版本化认知（versioned epistemology）。

落地为：/archive 研究归档 → 研究历程节点 → 继续研究。阅读教程

Ships as: /archive → research-journey milestone → Continue research. Read the tutorial

┌ 保留快照   按校验和固定当前字节
├ 原位保留   保留引用与校验和
└ 永久删除   仅限已登记的中间产物

→ 研究历程节点 · 继续研究

Full-fidelity Agent Trajectory

全保真执行轨迹

智能体的每一次工具调用、参数、返回、耗时与 token 消耗都被持久化为结构化轨迹，并以甘特时间线呈现。它不是日志，而是可审计的科研过程证据：何时、基于什么输入、得到了什么结果，一目了然。完整轨迹可一键导出为自包含 HTML，用于复盘、评审与方法学分析。

Claim–Evidence Binding

主张—证据精确绑定

论文中的每一项主张，都锚定到精确的产物版本（ArtifactVersion）、生成它的运行及已登记的输入，构成可追溯的证据谱系（provenance lineage）。定稿修订只读冻结；新修订继承而非改写历史证据，版本漂移与替代关系一目了然。

[ T-03 ] 基础设施

支撑长程科研的智能体基础设施

研究往往持续数周乃至数月。下面这些底层能力，让智能体在长周期、多环境、高风险的任务中依然可控、可查、可延续。

有状态计算连续体

每个项目、执行环境与语言独享常驻 Python／R 内核，命名空间跨单元、跨轮次持续存在，数据只需加载一次。

存档优先的无损上下文压缩

上下文用量达到 80% 时，先存档完整历史，再裁剪工具噪声、生成增量检查点摘要。旧对话从不被静默丢弃。

异构算力统一控制平面

本机、WSL 与 SSH 服务器共享同一套 Run 抽象：提交、监控、收取与传输，状态、日志和输出位置均有记录。大数据以带校验和的远程引用表示，而不是默认同步到本地。

可演化的智能体环境

项目级智能体宪章（AGENTS.md／.wisp/WISP.md）、/remember 记忆笔记、专家角色与技能库，让每一轮反馈都能改写下一轮的工作环境。

多智能体任务图编排

Agent Workflow 以依赖图（DAG）编排彼此独立的子任务，也能把已有技能拆解为任务图；/review 召唤审查员独立审阅，ACP 协议可调度外部编码智能体。

原生科学知识基座

23 个原生连接器、247 个工具直达 PubMed、UniProt、ChEMBL 等约 80 个数据库；外部 MCP 工具按需检索、渐进加载。

人在回路的细粒度干预

/rewind 回退重来、/fork 分支对话、/btw 旁路问答、随时停止智能体与取消 Run：研究者可以在任意时刻质询、修正、否决与重跑。

确定性行为评测门禁

持续集成在 Windows、macOS 与 Linux 上运行确定性的无头智能体评测套件，把智能体行为当作回归测试的契约，而不是演示。

本地优先与密钥隔离

项目与会话记录保存在本机数据库，文件留在工作区；API 密钥与 SSH 私钥交由操作系统钥匙串托管，从不写入数据库。
