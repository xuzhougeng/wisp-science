# SwiftUI 与 WebView 工作台对比（2026-10-08）

这次补齐了科研助理、论文证据编辑、专业查看器和工作流画布。两版复用
现有 Rust 服务与持久化数据；界面组织仍遵循各自平台。验收使用当前
1.18.0 QA 包和同一份合成项目数据，未操作正式项目或发送模型请求。

| 模块 | SwiftUI | WebView | 当前差异 |
| --- | --- | --- | --- |
| 科研助理 | 持续对话、可见项目上下文、日期计划、研究日历、自动化与每日回顾 | 持续对话、项目列表、侧栏日历、自动化 | 原生版通过按钮打开日历，宽屏显示计划侧栏；WebView 在三栏页面内同时展示项目和日历。WebView 另有定时任务模板快捷入口。 |
| 会话定时器 | 独立时钟按钮，保存、更新、启停、取消 | 会话选项中的定时器 | 使用相同调度器与轮次替换规则。原生版未知写入结果需要重新读取并确认。 |
| 论文证据 | 创建论文/版本、结构编辑、精确消息片段与其他来源、绑定状态、检查、豁免、冻结、校验、导出、克隆 | 全屏论文证据页面，按整理/检查/记录分区 | 原生编辑器采用窗口和嵌套编辑面板；冻结结果、来源定位和校验复用同一后端。 |
| PDF | PDFKit 翻页、缩放、搜索、选区与页码引用 | 离线 PDF 渲染器与文本层 | 绘制和文本选择由不同渲染器完成。 |
| Office | DOCX、XLSX、PPTX 离线预览，工作表/公式和选区引用 | 相同离线模块 | 外层工具栏与打开方式不同；原生版采用临时 WebKit 文档表面。 |
| HTML/科学文件 | HTML 阅读/源文本、FASTA、MSA、结构和分子预览 | 相同科学模块与 HTML 预览 | 原生 HTML 在不透明沙箱中允许内联脚本；预览只访问打包资源与经过项目校验的嵌入图片。 |
| 工作流 | 阶段与依赖曲线、节点编辑、依赖增删、拖动/平移/缩放、校验、复制/保存/删除、转换草稿 | 工作流库、画布、配置侧栏和连线端口 | 原生依赖通过检查器编辑；WebView 提供端口连线与双击空白添加。原生节点位置和相机只影响当前显示。 |

此次四个模块完成不代表全产品每个入口完全一致。例如 Hooks 设置仍由
WebView 提供；不同外壳保留原生窗口、字体、文件选择器与工具栏。

## 实际界面验收

- 原生助理正确列出三个可见项目；自动化编辑器立即按 Escape 只关闭
  顶层编辑器，保留自动化面板。新建验收任务保存后停用。
- 普通有效会话保存了 60 分钟定时器，显示下次运行时间，停用后退出
  面板。WebView 的自动化列表读取到上述两条已暂停记录。
- 两页 PDF 正常显示；搜索 `page 2` 定位到第二页，引用进入侧聊草稿时
  带上真实路径与页码。HTML 的中文、emoji 阅读与源文本切换正常，阅读
  选区引用保留来源。XLSX 的 `Results!C2` 引用包含值 `84` 和公式 `=B2*2`。
- 原生保存的论文包含中文/emoji 结构、精确 UTF-8 消息片段、已冻结 v1
  和可编辑 v2。导出的 ZIP 校验通过。WebView 可读取相同论文与冻结状态。
- 从内置文献工作流复制并保存验收模板，节点改名为 `synthesize_qa`；
  WebView 正确读取三个节点、两个阶段和两条依赖。立即 Escape 只关闭
  节点编辑器，保留父画布。
- 打包验收发现并修复两处问题：缩放后节点拖动重复换算距离；Office
  预览未启用布局样式，导致 Excel 网格线与表头背景缺失。
  重建后再次实测：69% 缩放时拖动 120×80 屏幕像素，节点同样移动
  120×80 像素；背景平移 100×50 像素也正确。Excel 网格恢复，RDKit
  离线分子图正常显示。

旧的“35 轮工具栏验收”会话是手工写入的零起始序号样例，违反正式存储
使用的正序号协议，原生校验拒绝该会话。定时器验收使用有效的空会话；
原论文证据记录保持不变。
