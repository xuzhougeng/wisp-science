# 科研版的个人助理来！

早上打开电脑，三个项目、七八段对话、一个昨晚跑到一半的 Run。第一件事往往不是做研究，而是回忆：昨天到底做到哪了？今天先干什么？那个差异分析跑完没有？

这些问题不难，只是零碎，而且每天都要问一遍。

最近，个人 Agent 正在从“一次次对话”变成“一个一直在的助手”：Grok Bot、Meta 的 Muse、OpenAI 的 Dots，都在做同一件事——你面对的不再是一堆聊天窗口，而是一个记得你、知道你在忙什么的助手。

Wisp Science 把这件事带进了科研：**科研助理**。

> 本文为功能介绍。示例中的项目名、对话与结果均为虚构，用于说明交互方式。

<!-- 配图：首页右上角「科研助理」入口 -->

## 它是谁：一条永不结束的对话

在 Wisp 首页右上角点击「科研助理」，打开的是一条**不属于任何项目、也不会新建第二条**的对话。

没有会话列表，不用找“上次那段聊天在哪”。你每次打开，都回到同一个助理、同一条对话流；之前聊过的内容按页加载，长对话沿用 Wisp 的归档式压缩，旧消息不会被悄悄丢掉。

它的定位很明确：**科研秘书，不是科研劳力。** 它负责知道发生了什么、记住你要做什么、把活交给对的人；真正的分析，交给项目里的对话去做。

## 它能做的四件事

### 一、汇报：昨天做了什么

> **你**：我昨天做了什么？
>
> **助理**：昨天有两个项目有记录：
> - **RNA-seq 衰老队列**：完成质控，3 个样本被标记为低质量；归一化比较的 Run 失败（内存不足）。
> - **文献综述**：新增两条发现记录，关于 SASP 标志物的定义分歧。

助理读取的是各项目**已经登记**的研究活动：运行（包括失败的）、产出文件、研究记录、对话中你提出的请求，以及每日研究回顾——和首页研究日历是同一份数据，只是换成了一句话就能问。

它只说记录里有的内容。没登记的事，它不会替你编。

### 二、记计划：今天打算做什么

> **你**：记一下，今天要把 Methods 写完，再催一下合作者的 ATAC 数据。
>
> **助理**：已记下今天的两项计划。昨天还有一项未完成：“复核 3 个低质量样本”，已一并列入今天。

计划逐条保存，带日期和状态（待办 / 完成 / 放弃）。没完成的条目会自动出现在今天的清单里。

关键在于：**计划存在对话之外**。对话再长、压缩多少次，你说过的计划都不会被“忘掉”。

### 三、派活：在某个项目里开始一项工作

> **你**：在 RNA-seq 项目里开个对话，把 batch 作为协变量重跑差异分析，输出前 50 个基因。
>
> **助理**：已在「RNA-seq 衰老队列」中新建对话“重跑差异分析（batch 协变量）”，任务已在后台开始，并记入今天的计划。

助理会在目标项目里新建一条带标题的对话，把一份完整、自包含的指令发过去。之后的工作由**那个项目自己的 Agent** 完成——它有项目的文件、运行环境、Skill 和服务器配置。需要审批的操作，仍然在那个项目里等你确认。

你不用切项目、不用新建对话、不用重新交代背景。

### 四、跟进：那个任务跑完没有

> **你**：刚才的差异分析怎么样了？
>
> **助理**：已完成。共 312 个基因 FDR < 0.05，前 50 个基因已保存为 `de_top50_batch.csv`。详见 RNA-seq 项目中的对话“重跑差异分析（batch 协变量）”。

助理会查看派出去的对话是否还在运行，并读取它的最终回答。

## 为什么它“不干活”

科研助理没有文件读写、没有 Shell、没有 Python/R 运行时，也不连 MCP 或外部 Agent。这是刻意的设计：

- **分工清楚**：助理管全局，项目管细节。分析的上下文、产物和运行记录，都留在它们所属的项目里，可追溯、可复现。
- **更安全**：一条跨所有项目的对话，最不该有的就是随手改文件、跑命令的权限。
- **不打架**：同一个问题不会一半在助理里、一半在项目里做。

你想让它“帮忙分析一下”，它会问你放到哪个项目，然后派过去。

## 它现在还做不到的

坦白说清楚边界：

- **不会主动推送**：晨报需要你开口问，它不会自己弹出来。
- **派出的任务完成后不会自动回报**：需要你问一句，或去项目里看。
- **计划暂不显示在研究日历上**。
- **只认登记过的记录**：没有注册的文件、随手敲的终端命令，它看不到。
- 隐私模式隐藏的项目，对助理不可见，也不能接收派活。

## 一个每天可以重复的用法

- **开工时**：“我昨天做了什么？今天有哪些没完成的？”
- **想到就说**：“记一下……”“在某某项目里让它……”
- **收工前**：“今天派出去的任务都怎么样了？哪些计划还没做？”

三句话，一天的科研节奏就清楚了。

**科研版的个人助理，帮你记住研究，而不是替你做研究。**
