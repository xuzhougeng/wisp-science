# 原生研究页面实施与验收

范围：承接 UI 对齐计划 E、F、G。交付研究历程主页面、正确日期网格的研究日历、论文证据只读工作区；不增加 Research Graph，不实现关系图编辑、补充记录写入、论文冻结或重现。

## 要求与完成证据

| 页面 | 必须交付 | 验证方式 |
| --- | --- | --- |
| 研究历程 | 项目内主内容、按本地日期/会话组织且去重、日期星期、会话与产物准确入口、摘要/来源详情、月份与日筛选、2000 条截断说明 | 纯分组测试，显式项目/会话/版本 ID 合同测试，空/失败/多天 fixture，返回会话与立即 Escape 实机检查 |
| 日历 | 主页面、月标题、周一到周日表头、月首占位、今天、项目筛选、独立活动标记、窄窗折叠项目区、当日研究历程入口 | 2026-09-01 星期二、闰年/跨年/DST 测试，隐私过滤和过期读取测试，宽窄窗口截图 |
| 论文证据 | 论文与修订选择、中文状态、结构列表与关联证据详情、来源 ID/快照、加载/无论文/无证据/失败区分，研究页隐藏会话面板 | 共用 DTO 增量字段与旧数据兼容测试，跨项目/跨版本拒绝与异步过期响应测试，同 paper/revision/item/binding 对照及窄窗检查 |

## 实现顺序

1. 修正日期数据与读取生命周期，建立可测试的日历网格与日/会话分组。
2. 扩展原生论文只读投影，保留已有权限和作用域检查；不以缺失数据虚构证据。
3. 将三页接入主内容导航，保留选中会话；所有返回/Escape 对当前页面生效，详情层优先关闭。
4. 用隔离合成 fixture 对照 WebView，记录相同 ID 的数量、来源、日期以及宽窄布局。
5. 定向测试后完成仓库要求的 Rust、Swift、wasm、Playwright 及构建/资源检查。

状态：已实现并完成验收。逐项证据、命令结果、实机复现步骤和已知限制见[研究页面验收记录](../../design-qa/ui-alignment-2026-09-28/research/README.md)与[画廊](../../design-qa/ui-alignment-2026-09-28/research/index.html)。

## 交付摘要

- 历程主页面按本地日期和会话 ID 分组；不可变产物版本通过新增共享 DTO 与 `native_research_journey_artifact` 读取，准确导航会话并保留返回状态。
- 日历使用 Calendar 日运算生成含占位的周一网格，分离日期/今天/活动数，支持宽窄布局、隐私项目过滤、月份/当日读取代次，拒绝过期响应。
- 论文只读投影扩展修订、结构正文、父子关系及证据绑定；同一请求验证项目和修订，切换先清空旧详情。显示中文状态和证据来源快照。
- 三页完成主内容导航、立即 Escape、宽窄实机检查，以及同 fixture 的 WebView 数量/日期/来源对照。研究页面隐藏无关对话工具栏、终端和侧面板，返回保留原会话。
- Rust workspace、Swift 全套、wasm、原生打包与资源同步均通过。Playwright 全量 880 通过/2 跳过/1 初始化超时；失败文件定向重跑 4 项通过，保留首次失败记录。

后续仍按原 E–G 边界推进关系图与记录编辑、论文定稿检查/版本记录查询及写操作，不将它们计入本次只读工作区。
