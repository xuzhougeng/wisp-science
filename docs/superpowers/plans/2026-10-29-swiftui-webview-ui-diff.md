# SwiftUI 与 WebView 界面逐页对比（2026-10-29）

结论：两个界面**还没有完全一致**。所有被比较的页面都有差异：有些是 SwiftUI 缺功能，有些是布局和文案不同，SwiftUI 还有几处明显的显示问题。

## 方法

- SwiftUI：从 `main`（`03033030`，1.22.0）用 `scripts/build_native_macos.sh` 构建的 debug 版 `target/native-macos/Wisp Science SwiftUI.app`。
- WebView：先启动 SwiftUI，再打开 `/Applications/wisp-science.app`。这时由 SwiftUI 的 helper 承载它打包的 1.22.0 前端，所以两边是同一个提交（设置页显示的版本是 v1.22.0）。
- 两边连的是同一个真实数据库，只做浏览、开关面板，不提交表单，也不发消息。窗口大小相近：WebView 1100×760，SwiftUI 1120×820。
- 下文中 **W** = WebView，**S** = SwiftUI。SwiftUI 窗口在后台时，"开"状态的开关会显示成灰色，这是 macOS 非活动窗口的正常表现，不算差异。
- 没有运行任何测试。

## 三、SwiftUI 的显示问题

已在源码中修复（未提交）。相关 Swift 单测通过；重新打包后已在界面上核对，第 1 项的内边距收紧和文件页大小格式是最后补的，未在界面上复核：

1. 产物等标签被挤出可见区：右侧标签栏和 WebView 一样只在当前标签上显示 ×，其余标签通过右键菜单关闭，内边距从 8 收到 6，默认 5 个标签不再溢出。
2. 用量的逐日列表出现未来日期：按后端已有的 `future` 标记过滤。
3. 收藏库弹窗没有关闭按钮：标题栏补上"关闭"。
4. 存储页加载时显示"Zero KB"：未读到数据时显示"计算中…"。
5. "自动压缩过长对话"的开关错位：设置行的说明列补上 `idealWidth`，长说明不再把开关挤到下方。
6. 自定义 GPSAdb 重复出现在内置连接器里：内置组只列 `bundled`，自定义连接的逐工具审批移到"自定义 MCP"对应行下。
7. 新建项目空表单仍可点"创建"：名称或目录为空时禁用，规则与 WebView 相同。
8. 未本地化的文案：内置快捷动作显示"文献调研"；补 openFDA 凭据名；思考强度显示"高 / 中 / 低"；"Agent 上下文"；权限范围显示"全局 / 项目 / 会话"；存储分类使用 WebView 图例名；环境设置里本机显示"本地"；轨迹用量行改为"第 1 轮 · 输入 12.8k · 输出 117 · 缓存 78%"，"来源"显示中文，标题旁不再显示原始模型 id。
9. 数据口径：文件（右侧文件页、产物列表、传输进度）和存储大小改为与 WebView 相同的 1024 进制、一位小数；用量的模型按模型配置合并（m1 → K3），超过 8 项时把排名第 8 及以后的合并为"其他模型"。

复核后不算差异：

- 轨迹里的 USER / ASSISTANT / TOOL / USAGE 徽标，WebView 也是这样显示。
- 输入框里的"Local"，WebView 也是这样显示。

尚未处理：

- 首次启动时报"查询服务已停止或超时"。重新打包后稳定复现：`wisp-service` 打开主库后，卡在打开项目库（`~/Desktop`、`~/Documents` 下的 `.wisp/project.sqlite`）的 `open()` 系统调用上，直到客户端的 30 秒超时。推测是新的 ad-hoc 签名触发了 macOS"访问桌面/文稿文件夹"授权，在等用户确认，但没有截到弹窗，尚未确认。
- 浮层（大纲、待查看）是灰色的固定高度面板，留白很多；WebView 是按内容自适应高度的白色卡片。
- 用量列表的数字仍是千分位原值，WebView 用 k 缩写。

WebView 这边也有两处可疑：

- "能力"弹窗里的"工作区"显示的是全局工作区目录（`~/Desktop/wisp-science-test`），不是当前项目的路径。
- 设置 › 远程接入里，飞书显示"未配置"，但开关是开着的；SwiftUI 对同一项显示"已启用"。

## 四、系统性的风格差异

- 设置页：S 每张卡片顶部多一行"全局设置 / 保存会提交…"的说明；W 的每个设置项多有一句用途说明，S 大多省略。
- 控件：W 常用开关、数字步进框、分段控件；S 常用复选框、纯文本框、原生下拉。W 的开关右对齐，S 有时紧跟在标签后面。
- 保存方式：W 有不少地方即时保存（外观、名单、网络逐行保存）；S 更多是整卡"保存 / 取消"。
- 图标按钮：S 首页的图标按钮都有白底描边卡片，W 是无边框的。
- 命名不一致：宠物 / 桌宠、快速配置 / 快速接入、禁用名单 / 阻止访问、全局习惯 / 全局记忆、按工具规则 / 按工具设置询问、对话目录 / 会话大纲、轨迹 / 运行轨迹、时长 / 耗时、待处理 / 待查看、反馈 / 反馈问题、项目目录 / 工作目录、描述 / 说明、SCIMaster / SciMaster、我·助手 / 你·Wisp Science。
- Markdown：W 的有序列表序号是青色、带缩进，分隔线通栏；S 的序号是黑色纯文本，分隔线只是一小段"———"。
- 顺序："AI 配置"分组里，W 是 模型/快捷动作/工作流/专家/记忆/钩子，S 是 模型/快捷动作/钩子/工作流/专家/记忆。

## 五、本轮没有对比的页面

- 研究历程、论文证据：WebView 的入口在侧栏"更多"下拉菜单里，后台无法展开；申请全屏控制时超时，没有拿到授权。
