# 订阅账号与 API 模型

## 产品语言

| 概念 | 中文 / English | 含义 |
| --- | --- | --- |
| 账号来源 | 订阅账号 / Subscription accounts | 登录已有账号，在账号下选择要使用的模型 |
| API 接入 | API 模型 / API models | 服务地址、API 密钥、模型与请求参数 |
| 请求格式 | 对话协议 / Conversation protocol | OpenAI Chat Completions、OpenAI Responses、Anthropic |
| 对话选择 | 默认模型 / Default model | 新建对话使用的模型；可以来自订阅或 API |

订阅是认证方式，不是对话协议。「模型」页提供「API 模型」「ACP Agents」「订阅账号」三个并列标签；API 模型列表、数量、快速接入和协议选择中不再出现订阅入口。既有订阅模型继续出现在对话模型选择器中。

## 页面与状态

- 订阅账号标签：ChatGPT、SuperGrok 各一张账号卡片，展示登录状态、管理登录、添加模型，以及该账号的模型列表。可添加多个模型，每个可以自定义别名、设为默认或移除。
- 登录详情：完成账号授权后保存账号，不自动创建模型。「添加模型」独立进入仅有模型 ID、别名的表单，复用已保存账号。浏览器登录为默认；设备码为替代方式，说明账号需启用设备码权限。等待授权是中性状态，成功和失败分别展示；手动回调放在浏览器登录后的备用步骤中。
- 订阅模型编辑页：仅允许编辑模型 ID 与别名。地址、密钥、协议、tokens、推理、请求头和视觉参数均不提供编辑控件；新模型使用服务商默认连接和模型目录上限。
- API 标签：只列 API 模型，计数排除两个订阅来源；ACP 标签保留原有功能。
- 原生 macOS 与 WebView 使用同样的导航、分类和术语。

取消、离开详情、切换设置页会取消当前登录；旧异步结果不能覆盖新流程。Escape 先返回订阅首页，再退出设置。

## 兼容与修复

保留 `openai_codex` 和 `xai_oauth` 持久化标识与 CLI 参数作为兼容适配器，避免改变既有对话和凭据引用；产品页面不再将它呈现为协议。继续使用系统密钥环。

令牌解析同时接受 OAuth `expires_in` 与访问令牌的 `exp`；错误不回显令牌正文。设备码的 HTML 403 不再误判为等待授权；登录及对话请求返回简短可操作的错误，保留 HTTP 状态。网络拦截不等价于凭据失效，不能承诺重登消除所有 403。

同步 origin/main 至 28a8b0ef（v1.15.0），接入远程 aa02eda7 的 xAI 设备码授权、令牌刷新和主机校验。重新登录并保存账号会更新该订阅现有模型的凭据，不改其模型 ID、别名和参数。

## 验证

离线 Rust 测试覆盖令牌解析、HTML 拦截与设备码等待；Playwright 覆盖页面分离、协议选项、双服务商、多模型、仅两项编辑、状态、取消与旧结果；原生设置测试及共享资源检查覆盖导航与分类。真实账号授权和受限网络可达性需在实际账号环境中复验。
